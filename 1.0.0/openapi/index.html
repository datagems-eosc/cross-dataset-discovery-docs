    DataGEMS Cross-Dataset Discovery Service v1¶

    The Cross-Dataset Discovery Service provides a secure API for performing natural language search queries across a pre-indexed collection of datasets, and for adding datasets to or removing them from that index.

    Terms of service: https://datagems.eu/terms
    Contact: DataGEMS helpdesk
    License: EUPL-1.2 license

    Search¶

    POST /corpus-analysis-search/¶

    Corpus Analysis Search

    Description

    Search for text passages answering a natural language question, with LLM assistance. An LLM first extracts the text request from the question (time-period, location and language constraints are extracted but not yet applied). The index is searched with that request, and the LLM then scores each candidate and drops those scoring below 3, so fewer than k results may be returned. If either LLM step fails, the original question and the unreranked results are used instead. Dataset access filtering is the same as POST /search/. Results also carry the item metadata.

    Input parameters

    Parameter In Type Default Nullable Description
    OAuth2Bearer header string N/A No JWT token for authentication, obtained from the OIDC provider.

    Request body

    {
    "dataset_ids": [
        "string"
    ],
    "k": 0,
    "query": "string",
    "search_mode": "sparse"
}

    POST /search-ap/¶

    Search via an Analytical Pattern

    Description

    Same search as POST /search/, but the request and response are DataGEMS analytical patterns. The search arguments are read from the properties of the node labelled CDD_Operator. In the response, any nodes previously connected as outputs of the operator are removed; one sc:Dataset node is added per result dataset and one cr:FileObject node per result object, with an output edge from the operator and a distribution edge from the dataset to each object. The full search response is merged into the pattern's metadata. A pattern without a CDD_Operator node, without query, or with invalid optional arguments results in a 500 error.

    POST /search/¶

    Perform a Search Query

    Description

    Submits a natural language query and returns a ranked list of relevant results. The search can be restricted to dataset_ids; this list is intersected with the datasets the caller holds a dg_ds-browse grant on, and results from any other dataset are always dropped. Callers with a privileged role (dg_admin, dg_system, dg_dataset-curator) are not filtered. If none of the requested datasets are permitted, an empty result list is returned.

    Input parameters

    Parameter In Type Default Nullable Description
    OAuth2Bearer header string N/A No JWT token for authentication, obtained from the OIDC provider.

    Request body

    {
    "dataset_ids": [
        "string"
    ],
    "k": 0,
    "query": "string",

    DELETE /dataset/{dataset_id}¶

    Delete a Dataset from the Index

    Description

    Removes all indexed points of a dataset. The caller needs a dg_ds-delete grant on the dataset or a privileged role. The source data is not touched.

    Input parameters

    POST /ingest/¶

    Ingest a Dataset

    Description

    Indexes a dataset described by a dataset profile (JSON) that the service reads from path_to_profile (a path on the service's mounted storage, e.g. /s3/...). The caller needs a dg_ds-edit grant on the profile's @id or a privileged role. Ingestion runs as a background job: the endpoint returns 202 with a job_id to poll via GET /ingest/{job_id}. The job record is saved before the job starts; if it cannot be saved, the request fails with 424. If the dataset is already indexed and replace is false, nothing is done and 200 with status skipped is returned.

    Input parameters

    Parameter In Type Default Nullable Description
    OAuth2Bearer header string N/A No JWT token for authentication, obtained from the OIDC provider.
    path_to_profile query string No Path to the dataset profile JSON, as seen by the service.
    replace query boolean False No Delete the dataset's existing indexed points and rebuild it from scratch.
